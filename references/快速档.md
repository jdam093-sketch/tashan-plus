# 快速档：详细做法

快速档是默认档。目标：用较少时间，交一页有出处、有"不迁移"、有"新东西"的笔记。
基础读取 `SKILL.md`、本文件和 `templates/一页笔记.md`；涉及外发或敏感材料时读隐私规则，记录技能意见时读纠正写回规则，不默认读完整档附录。

最多 1 次仅指需求澄清的计划内停顿；隐私、超限、法律判断冲突不计入。预计 API 费用超 ¥30、订阅额度不足或出现快用完提示，立即保存已有成果、停下请示；无人可问也不能继续消耗。

## 1. 定边界（最多停 1 次）

用一两句话复述：

- 这次要解决的主问题是什么；
- 本轮不做什么（比如不安装、不配置、不改主工程）；
- 要沉淀成什么（一页笔记，还是笔记 + 提示词草案）。

需求清楚就直接往下走，不问。需求含糊（看不出要学什么、要交什么）才停下问一次，问题合并成一条消息。
没人可问时，按最合理的理解继续，把"我是这样理解的"写进笔记的"待确认"一栏。

## 2. 先写已知（5 行，先存盘再看样本）

动手找资料前，先写下自己本来就知道的 5 条要点。作用：最后对照，看这次到底学到了什么新东西。

- 先建好一页笔记文件，只写第 1 节边界和第 2 节已知，**存盘后**再看任何样本。
- 用户随请求一起给了样本（同一条消息或同一个文件）：只读请求部分，样本段先不看；文件分段的，只读到样本段之前。
- 已经先看过样本：不要补写成"本来知道的"。第 2 节标题后注明「事后补记（已先看过样本）」，自查清单该项不打勾，局限里写明。

## 3. 找样本（3–5 个）

- 尽量覆盖：一个官方来源、一到两个高质量做法、一个反面或失败做法。
- 不只看用户给的那一个。
- 搜索词遵守 `references/隐私规则.md`：搜类别，不搜具体的人和内部文件。
- **每个样本都要真正打开看过**，记下来源、核验日期、等级：
  - **A 已核实**：打开了原文/官方页面，内容和结论对得上；
  - **B 二手**：只看到转述、摘要、别人的文章；
  - **C 未核实**：没打开、打不开、离线未核验的网上来源，或只凭印象。
- 真正打开过的本地原件按实际情况定级，注明“本地副本，版本 / 日期为……”；未知就写未知。本地 A 只支持副本内容，不代表网上最新状态；法规核验仍按领域模板。
- 任务方或用户提供的**合成/模拟/演练样本**：一律记 C 并标「合成」，本地打开过也不记 A；只能启发做法，不证明真实做法。全部样本都是合成时，自查"结论只建立在 A 级样本上"一项写「不适用：全为合成样本，结论仅作启发」。
- 只有 A 级样本能单独支撑结论；B 级要注明"据转述"；C 级只能列为"线索"，不能下结论。
- 涉及法规、合规的样本，按 `templates/领域-法律合规.md` 记效力层级、状态、适用地区。

样本不足 3 个时，照实写"样本不足"，不要凑数。

## 4. 拆三样（简版）

- **对象模型**：它把任务拆成哪些对象？输入、中间产物、最终输出各是什么？
- **工作协议**：谁先判断、谁执行、谁审核、哪里要人确认、什么情况打回？
- **质量门**：它靠什么防止低质量输出？

每样写三五行就够。拆隐含世界观、横向大表留给完整档。

## 5. 填一页笔记

用 `templates/一页笔记.md`。一页以内。必须填：样本索引（含等级和核验日期）、不迁移、这次学到的新东西、局限。

## 6. 自查

按一页笔记末尾的清单逐项打勾。有一项不过，就改到过，或在"局限"里写清楚为什么过不了。

## 7. 汇报

按 `SKILL.md` 第八节的话术。最后一行说明：要不要升完整档、为什么。

## 产出上限

不超过 3 个文件：一页笔记（必有）、提示词草案（需要时）、其它确有必要的一个文件。
